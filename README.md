# Akram Mahmoud Amer — Portfolio

A dark, modern developer portfolio built with **React + Tailwind CSS + Vite**.
Includes typing hero animation, animated skill rings, project filtering,
contact form and a full footer — matching the reference video design.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## Build for production

```bash
npm run build
```

## Structure

```
src/
  data/          skills & projects data
  components/    Navbar, Hero, Skills, Projects, Contact, Footer, ...
```

Edit `src/data/skills.js` and `src/data/projects.js` to customize content.
